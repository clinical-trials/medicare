# Health Affairs Scholar preparation

Prepared September 16, 2026. This package assesses a possible journal submission and specifies the work needed to turn the existing exploratory white paper into a systematic review. It is not a completed review, registration, submission, or promise of acceptance.

- [Proposed manuscript Methods text](manuscript_methods_proposed.md)

The protocol is a draft for investigator and methods-team review. No new database search, human screening, risk-of-bias assessment, registration, editor contact, or journal submission is represented as completed. Existing evidence and the published-on-GitHub preliminary white paper remain an exploratory pilot. Methods references are retained in the project's living bibliography and RIS export with verified PMIDs.

The scientific question, not anticipated editorial preference or the direction of results, determines inclusion and analysis. Null findings and differences that disadvantage men remain eligible.
